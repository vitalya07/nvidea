Политика разработана с целью обеспечения защиты прав и свобод пользователей при обработке их персональных данных.

1. Общие положения

1.1. Оператором персональных данных является [ФИО или наименование организации], далее — «Оператор».

1.2. Оператор осуществляет обработку персональных данных в соответствии с применимым законодательством о защите персональных данных.

1.3. Настоящая Политика распространяется на все персональные данные, которые Оператор может получить от пользователей при посещении Сайта, использовании его функциональности или заполнении форм обратной связи.

1.4. Оператор обеспечивает конфиденциальность персональных данных и принимает необходимые меры для предотвращения их неправомерного использования.

2. Категории обрабатываемых персональных данных

В зависимости от функциональности Сайта Оператор может обрабатывать следующие категории персональных данных:

  • имя и фамилия пользователя;
  • номер телефона;
  • адрес электронной почты;
  • сведения, содержащиеся в сообщениях и заявках пользователей;
  • технические данные, включая IP-адрес, тип устройства, браузер и операционную систему;
  • сведения о взаимодействии пользователя с Сайтом;
  • данные файлов cookie, если они используются.

Оператор обрабатывает только те данные, которые необходимы для достижения заявленных целей обработки.

3. Цели обработки персональных данных

Персональные данные пользователей могут обрабатываться в следующих целях:

  • приём и обработка заявок;
  • установление обратной связи с пользователями;
  • предоставление информации об услугах;
  • консультирование пользователей;
  • улучшение качества работы Сайта;
  • анализ посещаемости и поведения пользователей, если используются соответствующие инструменты;
  • обеспечение безопасности и предотвращение неправомерных действий;
  • исполнение требований применимого законодательства.

4. Принципы обработки персональных данных

При обработке персональных данных Оператор руководствуется следующими принципами:

  • законность и справедливость обработки;
  • ограничение обработки конкретными и законными целями;
  • недопущение обработки данных, несовместимой с первоначальными целями их сбора;
  • минимизация объёма обрабатываемых данных;
  • обеспечение точности и актуальности персональных данных;
  • хранение данных не дольше, чем этого требуют цели обработки или законодательство;
  • обеспечение безопасности и конфиденциальности данных.

5. Порядок обработки персональных данных

5.1. Обработка персональных данных осуществляется с использованием средств автоматизации и без их использования.

5.2. Персональные данные могут собираться посредством заполнения пользователями форм на Сайте, отправки сообщений и использования функциональных возможностей Сайта.

5.3. Перед отправкой персональных данных пользователь должен быть ознакомлен с соответствующими условиями их обработки.

5.4. Оператор не осуществляет обработку персональных данных, не имеющих отношения к целям их сбора.

6. Передача персональных данных

6.1. Оператор не осуществляет продажу персональных данных пользователей.

6.2. Передача персональных данных третьим лицам допускается при наличии законных оснований, в том числе:

  • при наличии согласия пользователя, если оно требуется;
  • когда передача необходима для обеспечения работы Сайта;
  • при использовании сторонних сервисов, необходимых для обработки обращений;
  • по законному требованию уполномоченных государственных органов;
  • в иных случаях, предусмотренных применимым законодательством.

6.3. При передаче персональных данных Оператор принимает необходимые меры для обеспечения их надлежащей защиты.

7. Сроки хранения персональных данных

7.1. Персональные данные хранятся в течение срока, необходимого для достижения целей их обработки.

7.2. По достижении целей обработки персональные данные подлежат удалению или уничтожению, если иное не предусмотрено законодательством.

7.3. Если пользователь отзывает согласие на обработку персональных данных, Оператор прекращает обработку и удаляет данные при отсутствии иных законных оснований для их дальнейшего хранения и обработки.

8. Защита персональных данных

8.1. Оператор принимает необходимые организационные и технические меры для защиты персональных данных от:

  • неправомерного доступа;
  • случайного уничтожения или изменения;
  • распространения без соответствующих оснований;
  • копирования и блокирования;
  • иных неправомерных действий.

8.2. Доступ к персональным данным предоставляется только лицам, которым он необходим для выполнения соответствующих обязанностей.

8.3. Оператор регулярно оценивает необходимость применения мер по обеспечению безопасности персональных данных.

Пользователь вправе:

  • получать информацию об обработке своих персональных данных;
  • требовать уточнения, исправления или обновления персональных данных;
  • требовать удаления персональных данных при наличии законных оснований;
  • отозвать согласие на обработку персональных данных;
  • требовать ограничения обработки в предусмотренных законодательством случаях;
  • обращаться с жалобами в уполномоченные органы по защите персональных данных.

Для реализации указанных прав пользователь может направить обращение Оператору по контактным данным, указанным в настоящей Политике.

10.1. Пользователь вправе отозвать ранее предоставленное согласие на обработку персональных данных.

10.2. Для отзыва согласия необходимо направить соответствующее обращение на электронную почту Оператора.

10.3. После получения обращения Оператор рассматривает его и прекращает обработку персональных данных, если отсутствуют иные законные основания для её продолжения.
